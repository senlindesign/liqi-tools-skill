# Answer Formats

Use the smallest format that preserves creator context, source, and uncertainty.

## Task mode

Return at most three candidates. For each include:

- Tool name and `已核对访谈` or `访谈线索`
- Fit and concrete scenario
- Creator and original interview link
- Short paraphrased evidence

If the task implies a multi-step process, give one relevant reviewed workflow case before the tool list.

## Workflow mode

Return:

1. The creator and task
2. The stages, each with its tools
3. One or two working principles
4. A limitation or context boundary
5. The original interview link

Prefer results labeled `已核对访谈`. Call a `访谈线索` a lead, not a complete workflow.

## Tool mode

Return:

1. Different use cases, not one averaged verdict
2. Creator names and source links
3. Explicit recommendation, use, past use, or negative evidence separately
4. A note that the source is historical when current product facts matter
